# 未央 Radar 2.0.2

本地新闻线索、研究笔记和草稿复核工具。Python 标准库服务配合浏览器界面；首次启动是空库，默认只监听本机。

## 安装与运行

安装 Python 3.9+（推荐 3.11+），下载并完整解压源码。在目录中运行：

```sh
python start.py
```

Windows 也可双击 `启动.cmd`。启动器会在 8765–8784 中选择空闲本机端口并打开浏览器。保留命令窗口，Ctrl+C 停止。不要直接打开 index.html。

备用：`python server.py --port 8765`，浏览器访问 `http://127.0.0.1:8765`。

## 使用

1. 手工添加线索或主动点击联网采集 RSS。离线练习可导入 `examples/offline-synthetic.json`，其中全部内容是编造数据。
2. 人工查看来源、填写证据与核实范围，保存研究笔记。
3. 规则模板或手工撰写草稿，补充事实、推断、反方、风险和来源。
4. 保存并执行规则初审，人工确认后审核通过；修改正文或证据会要求重新审核。
5. 导出保存的 Markdown 草稿，或备份 JSON、CSV、SQLite。

导入 V1 JSON 为追加操作，不覆盖已保存的核实与研究。JSON/CSV 导出用于查看和交接；V2 JSON 不支持一键导回。完整恢复应先停止服务、备份现有数据库，再在独立副本中验证 SQLite 恢复结果。

## 数据隐私与局限

数据在本机 `radar.sqlite3`，源码不携带用户数据库、手机配置或密钥。首次运行自动创建数据库，请自行备份，不要提交到公开仓库。

默认不联网；主动采集 RSS 或调用配置的外部服务才会产生网络请求。外部 AI 需要单独配置与同意发送数据；没有配置时不可用。规则模板不等于 AI，也不等于事实核查。外部来源可能延迟、不可访问或限制使用；引用与再发布须自行核实来源权利。

工具不会自动发布、交易或修改外部平台。不是行情终端、自动事实核查系统、多用户同步系统或断网 PWA。手机启动入口默认停用；保留的 mobile.py 是历史代码，不代表手机服务已经验证或启用。

## 开发验证

无需第三方测试依赖：

```sh
python -m unittest discover -s tests -p "test_*.py"
```

测试使用合成数据和隔离临时数据库，包括 HTTP、导入、审核、导出、安全边界和中文新闻处理。HTTP 测试需要本机回环网络访问权限。图标可用 `python tools/generate_icons.py` 重现。
